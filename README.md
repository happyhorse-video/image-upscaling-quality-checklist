# Image Upscaling Quality Checklist

A practical worksheet for preparing small product photos and web images for larger layouts. Published by the team promoting Upscayl AI at upscayl.app. This repository contains documentation only, not the service's source code.

## Start with the output size

Before processing an image, record its original dimensions and the intended display size. A 600 x 400 image displayed at 1200 x 800 needs a 2x increase on each axis. Increasing resolution is not evidence that missing details have been recovered.

| Check | Record |
| --- | --- |
| Original size | Width x height in pixels |
| Target size | Width x height in pixels |
| Intended use | Product page, thumbnail, presentation, or print |
| Details that must stay accurate | Labels, logos, materials, faces, or fine text |
| Export | Format, file size, and color appearance |

## A repeatable workflow

1. Keep the original file. Avoid enlarging an already enlarged export.
2. Crop only if the composition requires it; do not remove details needed for review.
3. Choose the smallest enlargement that meets your layout requirements.
4. Run a preview. One browser-based option is to [upscale image](https://upscayl.app/) with Upscayl AI.
5. Compare the result against the original at the same display size, then inspect at 100%.
6. Export a copy and inspect it in the final page or presentation.

Upscayl AI provides a browser workflow with enhancement modes, preview, and downloads. Current access limits and paid credit plans are shown on its website. This guide does not claim benchmark results or guarantee accurate reconstruction.

## Review before publishing

- **Edges:** Check for bright halos around objects and dark outlines.
- **Text:** Read every important letter and number; AI may alter small labels.
- **Textures:** Inspect hair, fabric, skin, and repeating patterns for invented detail.
- **Geometry:** Look for warped straight lines, uneven circles, and inconsistent symmetry.
- **Color:** Compare white backgrounds and brand colors with the source.
- **File weight:** A larger image may slow a page. Keep only the resolution you need.
- **Accuracy:** For catalog images, do not use an output that misrepresents the product.

## Simple decision rule

| Observation | Next action |
| --- | --- |
| Useful improvement with no important distortions | Export and check the final layout |
| Sharp edges but changed labels or texture | Try a less aggressive setting or keep the original |
| Severe source blur or missing detail | Request a higher-resolution source or retake the photo |
| Larger file with little visible benefit | Use a smaller export |

## Responsible use

Use images you own or are authorized to edit. Keep originals for provenance. Do not present AI-generated detail as forensic evidence or as a faithful recovery of information that is absent from the source.
